# 📁 Carpeta de Datos (`data/`)

Colocar aquí el archivo `.csv` limpio y normalizado una vez que el equipo termine el preprocesamiento.

## Checklist de validación antes de conectar a DuckDB
- [ ] Nombre del archivo y codificación (`UTF-8`) confirmados.
- [ ] Nombres de columnas estandarizados (`snake_case` recomendado para consultas SQL limpias).
- [ ] Tipos de datos consistentes (fechas en formato ISO `YYYY-MM-DD`, numéricos sin símbolos de moneda/texto).
- [ ] Manejo documentado de valores nulos y duplicados.
